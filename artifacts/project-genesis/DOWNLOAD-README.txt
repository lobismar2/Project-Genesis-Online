PROJECT GENESIS — PACOTE WEB

Modo solo:
1. Extraia o arquivo Project-Genesis-web.zip.
2. Abra dist/public/index.html no navegador.
3. Escolha uma classe e comece a explorar.

O modo solo, a campanha, o salvamento local, as habilidades e o progresso
funcionam sem servidor.

Cooperação:
O modo cooperativo depende do servidor da aplicação. Para publicar ou rodar
essa parte, use o projeto completo no Replit e mantenha o workflow da aplicação
e o API Server ativos.

Este pacote contém o build web mais recente e os assets necessários para abrir
o jogo localmente.

Assets visuais:
- `public/assets/pixel-ui/all.png` contém o atlas de interface fornecido.
- `public/assets/characters/` contém os sprite sheets e amostras dos personagens.
- `public/assets/dusk-icons/` contém o atlas Dusk Icons x24 e amostras aplicadas aos
  slots de arma, armadura e frasco.
- A origem foi fornecida pelo usuário; confirme a licença antes de publicar.
- O pacote RAR original não foi integrado porque precisa ser convertido para ZIP
  para ser extraído neste ambiente.
